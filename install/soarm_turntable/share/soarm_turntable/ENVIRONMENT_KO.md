# 화면을 보면서 환경 세팅

이 프로그램은 모터를 움직이지 않습니다. 기본 launch는 기존 두 카메라 영상을 구독하고 턴테이블 읽기 전용 브리지를 실행합니다. 로봇팔/펌프 노드는 실행하지 않습니다. Wizard 연결은 해제합니다.

## 실행
```bash
source /opt/ros/jazzy/setup.bash
source ~/robot_ws/install/setup.bash
export ROS_DOMAIN_ID=73
ros2 launch soarm_turntable environment.launch.py
```
카메라가 꺼져 있을 때만 `start_cameras:=true`, 턴테이블 브리지가 이미 켜져 있으면 `start_turntable:=false`를 붙입니다. 중복 실행하지 않습니다.

## 조작 순서
1. 카메라와 턴테이블을 고정합니다. 회전 범위의 케이블을 실제로 치우고 물체를 내립니다.
2. cam1 선택→영역 그리기→원본 화면에서 물체가 보일 영역 경계를 따라 6~10개 점 클릭→영역 확정.
3. cam2도 지정합니다. 위에서 보는 영상은 회전판 안쪽을 중심으로 잡고, 옆에서 보는 영상은 물체 높이까지 포함해 회전판 위쪽 공간을 잡습니다. 옆 영상에서 얇은 회전판 표면만 지정하면 물체가 잘립니다. 작업대·케이블은 제외하고, 배경에는 움직이는 사람이 없게 합니다.
4. **물체가 없는 상태**에서 빈 배경 10장 수집을 누릅니다. 정지 상태와 통신 수신이 확인돼야 합니다.
5. 물체를 올려 오른쪽 초록색 후보가 물체만 따라오는지 봅니다. 분홍색은 깊이 미확인 영역이며 빈 공간이라는 뜻이 아닙니다.
6. 깊이 차이(mm),유효 깊이 범위,최소 덩어리 픽셀을 조절합니다. 깊이 차이는 카메라 광축 방향 값으로 작업대 위 높이와 같지 않습니다. 기본10mm이므로 얇은 물체는 놓칠 수 있습니다.
7. 환경 저장을 누릅니다. 다음 실행 시 마지막 저장 환경을 자동 로드합니다.

저장 위치: ~/.ros/soarm4/environment/날짜_ID/environment.json, 카메라별 background_mm.npy(float32 mm), background_color.png. active.json은 최신 환경 경로입니다. 새 버전 폴더를 만들어 이전 설정을 보존합니다.

카메라·작업대·회전판·배경 케이블 위치가 바뀌면 다시 설정합니다. 해상도/내부행렬 변경은 검사하지만 카메라의 물리 이동은 자동 검출하지 못합니다. 회전판 표면의 깊이가 회전 중 달라지면 위양성이 생길 수 있어 회전축/평면 보정이 필요합니다.

## 촬영에 적용
원본 컬러·깊이는 보존하고 object_mask.png만 추가합니다.
```bash
ros2 run soarm_turntable turntable_scan capture --environment ~/.ros/soarm4/environment/active.json
```
scan에도 같은 옵션을 사용할 수 있습니다. 영점·토크·각도범위·정지 확인·로봇팔 정지감시 조건은 유지됩니다.

## 장치 없이 조작 연습
```bash
ros2 run soarm_turntable environment_setup --replay /절대경로/view_000 --output /tmp/environment_practice
```
재생 모드에서 저장한 환경은 실제 촬영에 적용할 수 없습니다.

## 한계
2D 영역/빈 배경 깊이 차이로 전경 후보를 만듭니다. 물체를 가리거나 붙어 있는 케이블의 자동 분리를 보장하지 않습니다. 투명·반사·깊이 결손·얇은 물체는 오검출/미검출될 수 있습니다. 마스크는 흡착 가능한 평면,25mm 컵 밀폐,충돌 안전성을 판정하지 않습니다. 실제 케이블은 회전 영역 밖으로 고정해야 합니다. 카메라-로봇/회전축 좌표 보정·3D 합성·자동 집기는 다음 작업입니다.
