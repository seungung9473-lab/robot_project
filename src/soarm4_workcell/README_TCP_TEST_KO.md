# TCP·엔코더 오차 시험

`tcp_error_test`는 기존 TCP 설정을 기준으로 목표 좌표·축을 수치 역기구학으로 풀고 MoveIt 경로와 충돌을 검사한다. `--execute`가 있을 때만 움직이며 결과와 관절 피드백을 test_data에 기록한다.

`random_tcp_plan`은 관절 한계 내 균일 난수로 도달 가능한 TCP 위치와 축 후보를 생성하고, 수치 역기구학으로 다시 계산해 50개 경로를 준비한다. TCP 공간에서 균일한 분포라는 뜻은 아니다. 속도 비율 0.5, 가속도 비율 0.1이다. 물리적 이동을 하지 않는다.

`random_tcp_execute <random_plans.json>`은 50개 계획의 출발자세와 경로 충돌을 재검사한 뒤 실행한다. 출발자세 변화가 0.5도를 넘거나 통신/실행에 실패하면 중단한다. 실행 중 예외 시 취소를 요청한다. 실제 엔코더는 기존 서보 브리지의 영점·방향·gain 변환을 거친 /joint_states이다.

기존 흡착컵 모델을 유지한다는 사용자 요청에 따라 새 삼각형 툴의 충돌 형상은 반영하지 않았다. 주변 임의 장애물도 모델에 없으면 검사되지 않는다. 현재 충돌 장면과 실제 배치가 맞는지 확인한 뒤 사용한다.

기록값은 정지 후 목표각 대비 실제각, 그 실제각을 FK로 계산한 TCP 오차이다. 외부 측정이 없으므로 실제 끝점 위치 오차·기구 처짐·TCP 길이 오차를 검증한 값이 아니다. 따라서 이 시험은 자동으로 영점·gain·TCP 보정값을 변경하지 않는다. 지속적인 오차가 관측되면 독립 검증 후 제어기 설정을 조정해야 한다.
