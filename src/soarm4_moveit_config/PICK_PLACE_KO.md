# 흡착·놓기 단계가 있는 픽앤플레이스

RViz의 SO-ARM4 Home 패널에서 사용합니다.

## 수동 버튼과 경로 저장

- **흡착 ON (수동)**: 실제 펌프를 켜고 압력을 확인합니다. 로봇은 이동하지 않습니다. 압력 확인 실패 시에도 펌프가 켜져 있을 수 있습니다.
- **놓기 / 해제 (수동)**: 펌프를 끄고 솔레노이드 밸브를 열어 잔압을 해제한 뒤 닫습니다. 로봇은 이동하지 않습니다.
- **흡착 단계 추가 / 놓기 단계 추가**: 선택 항목 뒤에 명령을 저장합니다. 이 버튼을 누를 때는 펌프가 작동하지 않습니다.
- 압력 diff와 흡착 확인 상태는 수동 버튼 아래에 표시됩니다. 실행 중에는 수동 명령과 경로 편집을 거부합니다.

## 자유 경로 목록 (version 4)

고정된 흡착 위치·놓기 위치 항목을 제거했습니다. 시작·종료 홈 사이에 일반 자세와 흡착·놓기 동작을 자유롭게 추가·이동·삭제합니다. **자세 추가**는 `자세 1`, `자세 2`처럼 이동 자세만 연속 번호로 표시합니다. 흡착·놓기 동작은 자세 번호에서 제외합니다.

기존 고정 위치의 좌표는 일반 자세로 변환해 보존하며 기존 동작 순서도 유지합니다. 이전 파일은 `*.v3-backup-*.json` 등에 백업합니다. 위치가 더 필요 없으면 해당 자세를 선택해 삭제하세요. CLI 편집 구간은 이제 `route` 하나입니다. 예: `pick_place.py insert route --index 0`.

아래는 이전 UI 설명입니다. 현재는 고정 흡착·놓기 위치 대신 일반 자세를 사용하세요.

## 이전 경로 만들기

1. 팔을 받치고 토크를 해제해 자세를 잡은 다음 다시 고정합니다.
2. **흡착 위치**, **놓기 위치**를 각각 선택하고 **선택 자세 저장**을 누릅니다.
3. 흡착 위치를 선택하고 **흡착 단계 추가**를 누릅니다.
4. 놓기 위치를 선택하고 **놓기 단계 추가**를 누릅니다.
5. 필요한 위치마다 **중간 자세 추가**를 누릅니다. 목록 순서를 확인하고 위/아래 이동 또는 선택 단계 삭제로 조정합니다. 동작 단계에는 관절 자세를 저장하지 않습니다.
6. **전체 경로 확인** 후 **1회 실행**합니다.

예시:
```
홈 (시작)
접근 중간 자세
흡착 위치
흡착 ON · 압력 확인
들어 올리는 중간 자세
놓기 위치
놓기 · 펌프 OFF/밸브 해제
복귀 중간 자세
홈 (종료)
```

홈과 두 위치 항목은 고정 앵커입니다. 각 앵커 사이에는 이동·흡착·놓기 단계를 추가할 수 있습니다. 흡착과 놓기는 순서가 맞아야 하며 마지막에는 놓기가 완료되어야 합니다. 잘못된 순서는 실행 전에 거부합니다.

**압력 확인 후 이동합니다.** diff=0 등 흡착 실패 시 운반하지 않습니다. 흡착 유지와 신선한 압력 피드백도 운반 중 확인합니다. 버튼 변경이 실제 흡착 불량을 해결하는 것은 아닙니다. 놓기 역시 압력 해제를 확인해야 다음 단계로 진행합니다.

STOP이나 오류 시 다음 단계로 진행하지 않으며 토크·흡착은 자동 해제하지 않습니다. 물체를 받친 뒤 수동 해제 버튼을 사용합니다. 토크 고정/해제 버튼과 HOME은 유지됩니다.

## 계획과 속도

전체 경로 확인은 이동 구간만 계획하며 실제 모터·펌프 명령을 보내지 않습니다. 실행은 검증된 계획을 재사용하되 시작 관절값과 충돌 장면을 확인합니다. 시작 오차가 0.01 rad를 넘으면 해당 구간을 다시 계획하며, 장면 변경 시 이전 계획으로 실행하지 않습니다. 이미 목표에 반 count 이내이면 불필요한 미세 이동을 생략합니다.

속도·ACC·피드백 제한은 기존 설정을 공유합니다. 중간점에서는 도착을 확인하므로 무정지 블렌딩은 아닙니다. 관절 자세 사이의 MoveIt 경로이며 직선 이동이나 컵 방향 유지가 보장되지는 않습니다. 등록하지 않은 작업대·물체·운반물은 충돌 검사에 포함되지 않습니다.

## 저장과 변환

기본 파일은 `~/.ros/soarm4/pick_place.json`, 형식은 version 3입니다. version 2는 원본을 `*.v2-backup-*.json`에 보존한 뒤 기존 흡착 위치 직후에 흡착 명령, 놓기 위치 직후에 놓기 명령을 삽입합니다. 기존 중간 자세와 순서를 유지합니다. 보정 정보가 다른 파일은 자동 실행하지 않습니다. version 1 역시 원본을 백업하며 호환되는 흡착·놓기 위치만 변환합니다.

## 터미널 대체 명령

```bash
ros2 run soarm4_moveit_config pick_place.py grip
ros2 run soarm4_moveit_config pick_place.py release
ros2 run soarm4_moveit_config pick_place.py insert_grip carry --index 0
ros2 run soarm4_moveit_config pick_place.py insert_release after_place --index 0
ros2 run soarm4_moveit_config pick_place.py list
ros2 run soarm4_moveit_config pick_place.py check
ros2 run soarm4_moveit_config pick_place.py run
ros2 run soarm4_moveit_config pick_place.py stop
```

## 검증 범위

가상 모터 버스·압력 노드와 실제 MoveIt/RViz를 사용해 단계 저장, 펌프 동작 없는 사전 검사, 전체 자동 순서, diff=0 운반 차단, 수동 버튼과 모터 이동 없음 조건을 검증합니다. 실제 USB 모터·펌프는 이 검증에서 사용하지 않습니다. 검증 결과는 동봉한 validation 파일을 확인하세요.
