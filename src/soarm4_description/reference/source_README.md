# SO-ARM4 STL v2 (로봇팔 + 전장 베이스 + 조립체)

## 1_로봇팔 (출력용, mm)
01~07 SO-101 공식 부품 / 08 J4 진공툴 v5 / 09 펌프 세움 브래킷

## 2_전장베이스 (출력용, mm, 전부 같은 조립 좌표라 그대로 불러오면 조립된 위치로 뜸)
10 상판 / 11 앞벽 / 12 뒷벽 / 13 기둥 **4개 출력** (네 모서리 ±87, ±72 에 같은 모양) / 14 하판
박스 200 x 170 x 95. 로봇 정면 = 박스 +x 쪽(옆면), 라즈베리파이 붙은 앞벽은 로봇 오른쪽.
SO-101 베이스는 길이방향이 박스 x축이랑 나란하게, 상판 구멍 4개(x ±35, y 10/45) 위에 올라감 → J1 축 = 박스 CAD (17.7, 27.5).

## 3_조립체 (보기용)
- `.glb` : 색 입힌 조립체 (윈도우 3D 뷰어로 바로 열림), 단위 m
- `_mm.stl` : 통짜 조립체, 단위 mm
- 좌표 = ROS `base_link` 와 동일 (원점 = 테이블 면, J1 축 바로 아래 / x 앞, y 왼쪽, z 위)
- 서보는 STS3215 형상으로 표시 (STS3250도 외형 같음), 컵/어댑터는 참고 형상
