# QR 유통기한 자동 분류

Gemini(ER2 우선, 기존 Flash 대체 설정 유지)가 스캔의 물체를 구분한다. SAM2와 실제 깊이·엔코더 각도로 물체별 형상을 만든다. Gemini가 물체별 여러 관측에서 인쇄된 숫자 날짜를 먼저 읽는다. 두 관측 이상에서 높은 확신으로 일치하지 않을 때만 ZXing으로 QR을 읽는다. 숫자 MM.DD는 실행 당시 연도로 계산한다. AI가 날짜나 관절 명령을 추측해서 실행하지 않는다.

사용자 확인 QR 형식: 물체 종류 영문자 1개 + YYMMDD. `O261101`은 종류 O, 유통기한 2026-11-01이다. 연도는 2000+YY로 해석한다. 숫자 날짜와 QR 모두 같은 물체의 서로 다른 관측 두 개 이상에서 일치해야 한다. 숫자가 확정되면 QR은 사용하지 않는다. 모순·미검출·잘못된 날짜는 이동 대상에서 제외하고 장애물로 유지한다.

한국 시간(Asia/Seoul)의 실행 당일 날짜를 자동으로 읽는다. 유통기한 당일까지는 유효하며, 유통기한이 오늘보다 이전일 때만 기한이 지난 것으로 판정한다.

- 지난 날짜: `trash_drop` 저장 자세로 운반, 실제 관절 도착과 압력 유지 확인, 펌프 OFF·밸브 개방으로 해제, 홈 복귀.
- 지나지 않은 두 날짜: 기준 날짜와의 일수 차이가 작은 날짜 → ID5, 큰 날짜 → ID6. 기본 기준은 오늘이다. 고정된 7일 기준은 사용하지 않는다.
- 같은 거리인 날짜는 둘 다 ID5로 분류하고, 기존 공동 배치 계산으로 겹치지 않는 자리를 예약한다. 서로 다른 유효 날짜가 3개 이상이면 임의 분류하지 않고 그룹 규칙을 요구한다.
- 모든 대상의 집기 순서·턴테이블 각도·충돌 경로를 첫 집기 전에 검사한다. 회전 후 접촉 재계산/영상 재확인은 하지 않는다. 흡착·유지 기준 -200, 속도·가속도는 실행 당시 RViz 값이다.

## 처음부터 실행

아래 명령은 실제 홈 이동·턴테이블 촬영·모터·펌프 동작을 수행한다. 물체를 배치하고 패드를 비우고 주변을 정리한 다음 사용한다. 모터·ESP32·턴테이블 브리지가 모두 제어 모드여야 한다. 현재 연결이 읽기 전용이면 시작 전에 차단하며, 브리지는 자동 재시작하지 않는다. 카메라 보정과 쓰레기통 위치가 그대로여야 한다.

```bash
source /opt/ros/jazzy/setup.bash
source ~/robot_ws/install/setup.bash
export ROS_DOMAIN_ID=73
python3 '/home/seungung9473/문서/ChatGPT/라파 대회/reconstruction/run_qr_expiry_cycle.py' --execute
```

특정 비교 날짜를 제시하려면 `--reference-date 2026-11-15`를 추가한다. 이때도 이미 지났는지는 실제 오늘 날짜로 판정하고, 남은 두 날짜의 가까움/멀어짐만 제시한 기준 날짜와 비교한다.

새 스캔 세션이 이미 있으면 다음으로 AI 인식·QR 분류·경로 검사만 수행한다. `--execute`를 추가해야 실제 집기/운반을 한다. 기존 컬러 분류 경로는 `color_sort_plan.before_expiry.json`으로 보존된다.

```bash
python3 '/home/seungung9473/문서/ChatGPT/라파 대회/reconstruction/run_expiry_sort.py' '/새 스캔 세션' --recognize --read-dates
```

## 저장과 검증 범위

쓰레기 자세: `/home/seungung9473/robot_ws/src/soarm4_workcell/config/named_poses.yaml`의 `trash_drop`.

각 세션에 `expiry_observations.json`(실제 QR 문자열·관측·이미지 해시), `expiry_route_report.json`(오늘·기준 날짜·목적지), `batch_*/batch_plan.json`, 개별 실행 기록을 남긴다. 날짜가 넘어가거나 보정/쓰레기 자세/정책/실행 코드가 바뀌면 기존 실행 계획을 차단한다.

자동 검사 39개 통과. 실제 QR 생성·해독→마스크 연결→지난 날짜/ID5/ID6 라우팅 통합 검사 포함. 보관된 형상을 이용한 MoveIt 가상 검토에서 접근·접촉·들어 올리기·쓰레기 자세 운반·빈 로봇 복귀 경로 통과. 검토 중 바꾼 충돌 장면은 복구한다.

새 날짜 분류의 실물 통합 시험은 아직 수행하지 않았다. 쓰레기통 내부 형상과 낙하 후 물체 상태는 모델링/카메라 검증하지 않는다. 저장된 쓰레기 자세는 사용자가 실물에서 지정한 위치다. 백그라운드 감시나 무단 자동 시작은 하지 않으며, 한 번 실행한 명령의 주기 안에서만 자동 분류한다.
