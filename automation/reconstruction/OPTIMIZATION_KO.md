# 중복 계산 정리

기준: main의 `1811d25988586116048b692379d72f0b8613b452`. 브랜치 전환·스테이징·커밋·푸시는 하지 않았습니다. 현재 mybranch 작업 폴더에서 누락된 main 파일을 복원한 뒤 아래 변경을 적용했습니다. 기존에 있던 파일은 복원 과정에서 덮어쓰지 않았습니다.

## 변경

1. 날짜 분류의 `--identity-only` 모드에서는 Gemini가 준 물체 식별 정보를 사용하고, 전체 점군 RGB를 다시 HSV로 바꾸는 색상 재분류 및 색상 목적지 선지정을 생략합니다. 목적지는 날짜 정책에서 한 번 결정합니다. 이 단계의 `color`는 `not_evaluated`, `destination_pad_id`는 null입니다. 물체 영역 추출에 사용하는 HSV 전경 필터와 점군의 실제 RGB는 유지합니다.
2. 날짜 인식용 사진 준비는 물체별 반복 처리 대신 촬영 시점·카메라별로 RGB 디코딩과 HSV 변환을 한 번 수행한 뒤 각 마스크에 적용합니다. 두 카메라의 최대 24개 관측, 사진 선택 점수, 잘라낸 픽셀, 마스크·신뢰도·일치 판정은 유지합니다.
3. 별도의 기존 색상 분류 모드에서는 로컬 색상 분류와 Gemini 색상 불일치 검사를 유지합니다.
4. 새 계산 모듈을 실행 계획의 파일 해시 검사에 포함했습니다. 수정 이전 계획은 다시 생성해야 합니다.

## 역할

- Gemini: 물체 식별과 인쇄 날짜 인식.
- 로컬: 마스크·깊이·점군·날짜 연산·목적지 규칙·IK·충돌·압력·엔코더 검증.
- AI가 더 빠르고 정확하다는 실측이 없는 수치 계산은 AI로 넘기지 않았습니다. API 호출 횟수와 입력 사진 수는 바꾸지 않았습니다.

## 검증

- 단위 테스트 48개 통과.
- 저장된 실제 3물체·24카메라 관측으로 수정 전후 입력 크롭의 픽셀·점수·순서가 모두 같음을 확인.
- RGB 디코딩과 HSV 변환: 각각 72회 → 24회.
- 같은 자료를 3번씩 준비한 중앙값: 2.166초 → 0.985초, 이 준비 단계 약 2.20배.
- 전체 로봇 사이클이나 Gemini 응답 시간이 2.20배 빨라졌다는 의미는 아닙니다.
- 모터·펌프 동작 및 실제 API 호출 없이 검증했습니다.
- 측정 기록: `test_data/runs/20261105_190318_c0e8fe2e/duplicate_work_benchmark.json`.

수정 파일: `process_three_color_objects.py`, `read_numeric_dates.py`, `batch_inputs.py`.
추가 파일: `identity_routing.py`, `date_crops.py`, `tests/test_duplicate_work.py`, 이 문서.


## 추가 공유 계산 최적화

- SAM2: `apply_sam2.py --sessions OBJECT1 OBJECT2 ...`가 모델을 한 번만 로드하고 같은 원본 이미지의 특징을 공유합니다. 물체별 양성·음성 점, 박스, 마스크 후보 선택, 면적 검사와 가림 처리는 독립적으로 유지합니다. 기존 `--session OBJECT` 명령도 지원합니다.
- 흡착면 준비: 프레임·카메라별 깊이→테이블 좌표 변환을 한 번만 수행한 뒤 각 물체 마스크를 적용합니다. 프레임 단위로 처리하므로 전체 해상도 좌표 영상을 모두 캐시에 쌓지 않습니다. 물체별 관측 점은 기존과 같이 보존합니다.
- 평면 평가: 동일 평면의 2D 검색 트리·투영 좌표·컵 원판 샘플을 후보 중심 간에 공유합니다. 두 카메라 일치 검사에서도 관측별 검색 트리를 공유합니다.
- 첫 프레임의 전경 계산을 초기 중심 계산과 프롬프트 준비에 재사용합니다.
- 날짜 분류 모드의 복원 단계에서는 `--no-preview`로 미리보기 PNG·병합 PLY 생성을 생략합니다. 카메라별 점군·RGB, 분석용 병합 점군, 마스크 검토 그림과 RViz용 데이터는 유지합니다. 독립 `reconstruct.py`의 기본 미리보기 동작은 유지합니다.
- 수치 계산을 Gemini에 넘겼을 때 더 빠르고 정확하다는 비교 근거는 확보되지 않아 추가 원격 호출을 넣지 않았습니다. 물체·인쇄 날짜 인식은 Gemini, 물체 경계는 로컬 SAM2, 날짜 연산·좌표·IK·충돌·센서 검증은 로컬입니다.
