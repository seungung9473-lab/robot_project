# Gemini 색상 분류

- Gemini ER2를 기본으로 사용하고, 기존 모델 전환 정책을 유지한다.
- 턴테이블 위 세 물체를 각각 인식한다. 같은 색 두 물체도 개별 ID로 유지한다.
- 빨간색 → 로봇 기준 오른쪽 ID6, 초록색 → 왼쪽 ID5.
- Gemini는 식별만 담당한다. SAM2 마스크의 실측 RGB 색상과 일치해야 배정한다.
- 촬영은 30도 간격 정지 촬영 12회 후 0도로 복귀한다.
- `process_three_color_objects.py SESSION DETECTION_JSON`은 물체별 마스크·점군과 `color_sort_plan.json`을 만든다. 모터를 움직이지 않는다.
- 경사면/옆면 후보는 `plan_inclined_pick.py SESSION`으로 계산한다. 90도까지 후보에 포함하지만 관절 리미트·밀착 면적·새 영상·충돌 검사를 통과해야 실행한다.
- 같은 색이 두 개라도 패드가 차 있으면 자동으로 쌓지 않는다. 공간 확인/물체 제거 후에만 다음 물체를 옮긴다.
- 기존 흡착 기준 -300, 1mm씩 최대 3회 재시도를 유지한다. 비평행 흡착/5회 시험은 사용하지 않는다.
- 전체 3개를 연속 운반하는 자동 실행기는 아직 구성 중이다. 기존 두 물체 크기 분류 실행기를 사용하지 않는다.

## 2026-11-04 실측 결과

Gemini ER2가 초록색 경사 블록, 빨간색 블록, 초록색 홈 블록을 각각 검출했고 SAM2 점군 RGB 색상과 일치했다. 목적지는 ID5 / ID6 / ID5다. 새 영상의 접촉 원판 검증을 통과하지 않아 실제 흡착·운반은 실행하지 않았다. 자동 분류 전체 성공으로 판정하지 않는다.

## 여러 물체 재시험 설정

1~8개 Gemini 검출 개수를 처리하며, 회색은 사용자 지정에 따라 오른쪽 ID6로 배정한다. 주변 물체는 실측 점군의 볼록 메시와 1mm 여유로 유지한다. 음수 여유로 물체 형상을 줄이는 것은 허용하지 않는다. 볼록 메시이므로 홈과 오목한 부분은 채워질 수 있다. 패드의 2mm 가장자리 여유, 접촉점의 새 RGBD 확인, 기존 관절/압력 검사는 유지한다.
