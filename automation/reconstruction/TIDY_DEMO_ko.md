# “테이블 정리해” 자연어 시연

텍스트 명령을 Gemini가 해석해 **등록된 턴테이블 유통기한 분류 작업**으로 연결한다. 테이블 전체 청소나 임의 물체 폐기를 지원한다고 표현하지 않는다. 음성 인식은 포함하지 않는다.

## 바로 사용

```bash
# 안내만: API·ROS·실물 동작 없음
~/robot_ws/run_tidy_demo.sh "테이블 정리해"

# Gemini 명령 해석만: 텍스트 API 호출, 모터·펌프 명령 없음
~/robot_ws/run_tidy_demo.sh "테이블 정리해" --interpret

# 실제 시연: HOME·회전 스캔·진공·집기·분류까지 동작
~/robot_ws/run_tidy_demo.sh "테이블 정리해" --execute
```

현재 데스크탑에서는 `TUMST_test` 작업공간의 새 진입점이 설치된 `~/robot_ws_mybranch` GPU 백엔드를 사용한다. 백엔드를 바꾸려면 `SOARM_DEMO_BACKEND` 또는 `--backend-root`를 명시한다. main을 바꾸거나 브랜치를 자동으로 merge하지 않는다.

## 한 번의 시연 흐름

1. Gemini가 명령을 `expiry_sort`, `clarify`, `unsupported` 중 하나로 해석한다. 임의 좌표·속도·명령은 받아들이지 않는다.
2. 실제 실행 모드에서만 CUDA·도메인73·브리지 제어모드·빈 컵 상태를 확인한다.
3. 새 실행 시작에서 패드 5·6의 이전 배치 모델만 삭제·확인 → Pilz PTP 우선 HOME → 듀얼12방향 정지촬영 → 0° 복귀.
4. 기존 물체 식별 → GPU FP32 SAM2 → 외형·흡착면·IK 계산.
5. 인쇄 날짜 우선, 불확실하면 QR 보완. 날짜 계산과 목적지는 로컬 고정 정책으로 결정한다.
6. 현재 장면의 기존 배치 물체를 반영해 패드 전체의 2mm 격자에서 빈자리를 찾고, 단일·다중 물체 공간을 함께 예약한다. 패드 가장자리와 물체 사이의 2mm 여유를 유지한다. 기존 점유 때문에 후보를 못 찾으면 같은 재스캔을 반복하지 않는다.
7. 전체 순서·접촉·운반·놓기·복귀 경로를 검사하고, 모두 통과한 경우에만 기존 실행기로 동작한다. 불확실한 날짜는 이동하지 않는다.

계산 중에는 5초 간격으로 단계·경과 시간을 출력한다. 실패 사유와 재탐색을 표시하며, 실행 전 경로 실패는 빈 컵·홈·정지 확인 후 최대 1회 재스캔한다. 집기 도중 실패는 자동 재시작하지 않는다. 세부 조건은 PLANNING_STATUS_ko.md에 있다.

## 시간과 기록

- 백엔드 `automation/test_data/index.csv`, `runs/`에 `start_trial` 기록.
- `demo_result.json`: 실제 단계별 시간, 전체 경과시간, 완료/중단, 날짜 분류, 완료한 물체 목록.
- `execution.log`: 기존 실행기 출력.
- `telemetry.jsonl`: 실제 관절값·압력diff·턴테이블 상태. 측정하지 않은 센서값은 생성하지 않는다.
- CPU 자동 대체 없이 CUDA를 요구한다. GPU 미지원 기하·날짜 계산·충돌 검사는 CPU, Gemini는 원격 API이므로 총시간을 GPU 단독 시간으로 표현하지 않는다.
- 기존 계획 재사용과 동적 압력·엔코더·시작 자세 확인을 유지한다. 모델 판단으로 안전검사·속도/압력/관절 한계를 변경하지 않는다. 속도는 현재 RViz 설정을 사용하며 이 코드가 최대속도로 올리지는 않는다.

## 준비 조건과 검증 범위

진공·서보·턴테이블 제어 브리지, 카메라2대, MoveIt·작업대 장면·제어용 RViz가 먼저 실행돼 있어야 한다. 새 진입점은 장치 드라이버를 중복 기동하지 않는다. `--execute`는 실물 동작 승인에 해당하므로 작업대가 실제 실행 준비 상태일 때만 사용한다.

검증: 비구동 테스트10개 통과, 셸 문법/기본 안내 실행, 실제 Gemini 명령 해석1회 확인, 저장된 실제 점군의 패드 위치 예약 확인. **새 자연어 진입점으로 전체 집기·놓기는 아직 실물 검증하지 않았다.** 이전 전체 시도는 경로 이식 오류와 놓기 외곽 조건에서 중단됐으며 성공으로 합산하지 않는다.

중단 시 자동 펌프 해제나 토크OFF를 보내지 않는다. 이미 물체를 들고 있는 상태라면 기존 RViz STOP/상태를 확인해야 한다. 임의 재시작이나 과거 계획 재실행으로 이어가지 않는다.
