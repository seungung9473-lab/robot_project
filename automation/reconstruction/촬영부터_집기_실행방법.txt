홈 → 촬영 → 형상 복원 → 흡착 후보 → 집기 시험

준비: 현재 hardware bringup, 양쪽D415 정렬깊이, turntable 브리지가 실행되어 있어야 함.
이 명령은 실제 로봇·턴테이블·펌프를 작동시킴. 물체와 주변 준비 후 실행.

현재60mm 빨간 시험블록으로 반복하는 명령:
source /opt/ros/jazzy/setup.bash
source ~/robot_ws/install/setup.bash
export ROS_DOMAIN_ID=73
python3 '/home/seungung9473/문서/ChatGPT/라파 대회/reconstruction/run_scan_to_pick.py' --execute --measured-surface-z 0.119

순서:
1. 실제 홈 서비스 성공 확인
2. 턴테이블0,-30,...,-330° 정지촬영. 총12시점×2카메라. 끝나면0°복귀
3. SAM2로 물체 분할, 측정각도로 관측 표면 점군 복원
4. Ø25mm 컵과3mm 가장자리여유, 깊이커버리지, 패치평탄도 기준으로 후보 생성
5. 다각도 전체형상은 보존하고0°정지영상에서 접촉점을 다시 구함. 기준을 통과하고 가장자리 여유가 큰 후보를 선택. 같은 점이 반대 카메라 표면에서도3mm 이내이며 면 법선 차이가5° 이내여야 함
6. 실제관절값, 턴테이블영점, 도달가능여부, MoveIt충돌검사. RViz 속도/가속도 비율 적용
7. 위에서 접근 → 접촉 → 진공확인 →10mm상승목표 →같은접촉높이로복귀 →펌프OFF·밸브개방·닫기

현재설정: 처짐보정2°, 상면기준아래로2mm 접촉목표. 실제힘제어/정확한눌림량보장이아님.
measured-surface-z0.119는 턴테이블59mm+현재블록60mm에대한 실측상면높이임.
이높이를다른물체에재사용하지말것. 다른물체에서는 생략하면 새깊이기반높이를사용하지만 현재Z오차검증이더필요함.
SAM2 초기프롬프트는 원판 위의 깊이전경에서 생성하며 색상을 가정하지 않음. 현재는 단일 대상만 허용하며 다중물체 선택·ER2연결은 아직 구현하지 않음.
흡착실패시 더누르거나리프트하지않음. 리프트후진공이상시 모션중단, 펌프유지상태로 실제상태확인필요.
완전수평·형상정밀도는별도검증필요. 자동으로보정각/압입을증가시키지않음.

결과: reconstruction/multiview/새세션/ 에 원본촬영·SAM2마스크·PLY점군·흡착후보·pick_trial*/기록 저장.
재구성만: python3 process_scan.py /절대/세션/경로
새세션의 집기전검사만: python3 execute_scan_pick.py /절대/세션/경로
기존시험폴더를덮어쓰지않도록 반복실행은새스캔 또는 --trial-name 새이름 사용.

중심 밖 물체: 중심밖_물체_처리설명.txt 참고. 원판과 로봇 도달 범위 안에서 사용. 실물검증이 끝나기 전 정확도 보장 아님.
